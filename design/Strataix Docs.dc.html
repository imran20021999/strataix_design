GET STARTED · INTRODUCTION

Welcome to Strataix

The control plane for production AI. One gateway in front of Anthropic, OpenAI, Google and others — with the routing, guardrails, budgets and audit trail you'd otherwise build yourself.

Quickstart · 5 minFrom zero to a working request with your existing SDK. Concepts tourGateway, routes, guardrails, budgets, sessions.

In 60 seconds

Point your existing Anthropic, OpenAI, or Google SDK at the Strataix base URL and give it a Strataix key. Your code doesn't change — but everything you send now shows up in a dashboard, can fall back to a second provider, and respects the budgets and guardrails you set.

Python Node cURL Go
Copy 
# pip install anthropic
from anthropic import Anthropic

client = Anthropic(
  base_url="https://gateway.strataix.in/v1",
  api_key="sk_live_…",
)

msg = client.messages.create(
  model="claude-sonnet-4",
  max_tokens=1024,
  messages=[{"role": "user", "content": "ping"}],
)
print(msg.content[0].text)
Nothing to install. Strataix is compatible with the official Anthropic, OpenAI, Google and Mistral SDKs — same API surface, same request shapes.

What you get out of the box

Routing & fallbacks

Primary + ordered fallbacks on 5xx, 429 or timeout. Promote a canary with an A/B split.

Guardrails

PII redaction, prompt-injection, toxicity and secret detection — applied before the request leaves your network.

Budgets

Set caps by team, route or key. Warn, downgrade or hard-stop based on your policy.

Traces

Every LLM call, tool call and guardrail check as a span. Replay and share like you would a profile.

Quickstart

  1. Sign in and create an organization.
  2. Connect a provider — we never see their key.
  3. Issue a Strataix key with the scopes your app needs.
  4. Point your SDK at gateway.strataix.in/v1 and send a request.
  5. Open the dashboard · your request is already there.
